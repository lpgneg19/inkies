# Project background

Inkies is a lightweight macOS editor and live interactive previewer for the Ink narrative scripting language (by inkle). It provides writers and game developers with a sleek, localized environment to write branching storylines and test game logic in real-time.

## Goals
- Deliver a native macOS editor dedicated to Ink narrative scripting.
- Provide live, interactive story playtesting with knot navigation.
- Full parity with official inkle Inky template specifications.
